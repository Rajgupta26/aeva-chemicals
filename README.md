# Aeva Chemicals — Landing Page

Animated landing page for Aeva Chemicals, makers of textile auxiliaries for reactive dyeing (AeSop soaping agent, AeKomala cationic softener).

Static site: `index.html`, `styles.css`, `script.js`, and `assets/` (hero particle video and poster).

## Run locally

```bash
python3 -m http.server 5288
```

Then open http://localhost:5288.
